# Website wifianalyzer.schoepf-tirol.at

Statische Landingpage ohne Build-Schritt und ohne externe Abhängigkeiten.

**Veröffentlichen:** `index.html` und `icon.png` in das Web-Verzeichnis von
`wifianalyzer.schoepf-tirol.at` hochladen. Fertig.

- Der Download-Button zeigt auf `https://github.com/zenutrix/wifianalyzer/releases/latest/download/WiFiAnalyzer.exe`.
  Er liefert damit immer die neueste Version, ohne dass die Seite angepasst werden muss.
- Die Sprache (Deutsch/Englisch) folgt der Browsersprache und lässt sich oben rechts umschalten.
- Hell/Dunkel folgt der Systemeinstellung.
- **Impressum:** Im Footer ist ein Platzhalter-Link `#impressum`. Dort den Link zu deinem Impressum eintragen.
  In Österreich ist es Pflicht (§ 5 ECG / § 25 MedienG).

Alternativ lässt sich der Ordner auch über GitHub Pages veröffentlichen.
