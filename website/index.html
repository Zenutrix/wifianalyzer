FAQ

Häufige FragenFrequently asked

Warum braucht die App den Standortzugriff?Why does the app need location access?

WLAN-Netze verraten den Aufenthaltsort. Deshalb gibt Windows BSSIDs und Signalstärken nur an Apps heraus, die auf den Standort zugreifen dürfen. Der WiFi Analyzer ermittelt selbst keine Position und speichert keine Standortdaten.Wi-Fi networks reveal where you are, so Windows only hands out BSSIDs and signal strengths to apps that may access the location. WiFi Analyzer itself does not determine or store your position.

Windows SmartScreen warnt beim Start – ist das normal?Windows SmartScreen warns on start – is that normal?

Ja, solange die Dateien nicht digital signiert sind. Über „Weitere Informationen“ → „Trotzdem ausführen“ startet das Setup. Der Quellcode ist öffentlich, jedem Release liegen SHA-256-Prüfsummen bei.Yes, as long as the files are not code-signed. Choose “More info” → “Run anyway”. The source code is public and every release ships SHA-256 checksums.

Brauche ich Administratorrechte?Do I need admin rights?

Nein. Das Setup installiert standardmäßig nur für dich. Wer möchte, wählt „für alle Benutzer“ – dann fragt Windows nach Adminrechten.No. By default the installer installs just for you. Choose “for all users” if you like – then Windows asks for admin rights.

Wie bekomme ich einen Bericht für meinen Kunden?How do I get a report for my customer?

Messung starten, in jedem Raum Enter drücken und den Raum eingeben. Danach unter „Export“ den Bericht erstellen – er öffnet sich im Browser und lässt sich mit Strg+P als PDF speichern.Start a survey, press Enter in each room and type its name. Then create the report via “Export” – it opens in the browser and can be saved as PDF with Ctrl+P.

Wo werden meine Messungen gespeichert?Where are my surveys stored?

Automatisch im Ordner „Dokumente\WiFi Analyzer“. Auf der Seite „Messung“ lassen sie sich jederzeit wieder öffnen, ergänzen und exportieren.Automatically in the folder “Documents\WiFi Analyzer”. On the “Survey” page you can reopen, extend and export them at any time.

Was misst der Speedtest – und wie viele Daten braucht er?What does the speed test measure – and how much data does it use?

Pro Messpunkt misst die App den Ping zum Router und ins Internet. Der Speedtest ist optional: Er lädt bis zu etwa 6 Sekunden über speed.cloudflare.com herunter und hoch (bis ca. 70 MB) und zeigt damit die tatsächliche Internet-Geschwindigkeit an dieser Stelle. Er läuft nur, wenn der Laptop mit dem gemessenen Netz verbunden ist.At every point the app measures the ping to the router and to the internet. The speed test is optional: it downloads and uploads for up to about 6 seconds via speed.cloudflare.com (up to approx. 70 MB) and shows the real internet speed at that spot. It only runs while the laptop is connected to the surveyed network.

Welche Daten werden übertragen?Which data is transmitted?

Keine Messdaten. Einmalig wird die öffentliche Hersteller-Datenbank (Wireshark/IEEE) geladen; abschaltbar prüft die App bei GitHub, ob es eine neue Version gibt. Der optionale Speedtest nutzt speed.cloudflare.com, der Ping 1.1.1.1.No measurement data. The public vendor database (Wireshark/IEEE) is downloaded once; optionally the app checks GitHub for a new version. The optional speed test uses speed.cloudflare.com, the ping 1.1.1.1.
