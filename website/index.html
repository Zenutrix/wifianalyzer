FAQ

Warum braucht die App den Standortzugriff?Why does the app need location access?

WLAN-Netze verraten den Aufenthaltsort. Deshalb gibt Windows BSSIDs und Signalstärken nur an Apps heraus, die auf den Standort zugreifen dürfen. Der WiFi Analyzer nutzt selbst keine Standortdaten.Wi-Fi networks reveal where you are, so Windows only hands out BSSIDs and signal strengths to apps that may access the location. WiFi Analyzer itself does not use location data.

Windows SmartScreen warnt beim Start – ist das normal?Windows SmartScreen warns on start – is that normal?

Ja, solange die EXE nicht digital signiert ist. Über „Weitere Informationen“ → „Trotzdem ausführen“ startet sie. Der Quellcode ist öffentlich auf GitHub einsehbar, die Prüfsummen liegen jedem Release bei.Yes, as long as the EXE is not code-signed. Choose “More info” → “Run anyway”. The source code is public on GitHub and every release ships checksums.

Welche Daten werden übertragen?Which data is transmitted?

Keine Messdaten. Einmalig wird die öffentliche Hersteller-Datenbank (Wireshark/IEEE) geladen, und – abschaltbar – prüft die App bei GitHub, ob es eine neue Version gibt.No measurement data. The public vendor database (Wireshark/IEEE) is downloaded once and – optionally – the app checks GitHub for a new version.

Was kostet der WiFi Analyzer?How much does it cost?

Nichts. Er ist freie Software unter der GNU GPL v3 – auch für den beruflichen Einsatz.Nothing. It is free software under the GNU GPL v3 – including professional use.
